# 点検野帳カメラ サポートページ

GitHub Pagesで公開する、iPad向け点検写真アプリ「点検野帳カメラ」のサポートページです。

## 公開サイトURL

- サポートページ: https://appokayou.github.io/tenken-note-camera/
- プライバシーポリシー: https://appokayou.github.io/tenken-note-camera/privacy.html
- App Store: https://apps.apple.com/jp/app/id6784942986
- 関連アプリ「点検野帳」: https://appokayou.github.io/tenken-note/
- お問い合わせ: appokayou@gmail.com

## SEO対応内容

- titleタグを「点検野帳カメラ｜橋梁点検・現場写真の撮影と整理をiPadで」に変更
- meta descriptionを、橋梁・構造物点検の現場写真撮影、写真番号、コメント整理が伝わる内容に改善
- h1を1つに整理し、h2/h3で「このアプリでできること」「利用シーン」「基本の使い方」「FAQ」を構成
- ファーストビューに、誰向けか、何ができるか、何が楽になるかを明記
- App Storeへの導線をページ上部、機能説明後、ページ下部に配置
- canonical、Open Graph、Twitter Card、favicon、画像altを追加
- MobileApplicationとFAQPageのJSON-LD構造化データを追加
- robots.txtとsitemap.xmlを追加
- 点検野帳との相互リンクを追加
- 既存のVersion 1.0.1説明と利用上の注意を維持

## 公開後に行う作業

1. Google Search Consoleで `https://appokayou.github.io/tenken-note-camera/` を登録する。
2. URL検査でトップページを検査し、インデックス登録をリクエストする。
3. サイトマップ `https://appokayou.github.io/tenken-note-camera/sitemap.xml` を送信する。
4. 数日から数週間後に、検索パフォーマンスで「点検写真 アプリ」「点検写真 管理」「橋梁点検 写真整理」「現場写真 iPad」などの表示回数、クリック数、掲載順位を確認する。

## ファイル構成

- `index.html`: 公開サポートページ
- `privacy.html`: プライバシーポリシー
- `robots.txt`: クローラー向け設定
- `sitemap.xml`: 公開ページ一覧
